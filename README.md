# CognODB Cloud Benchmark

A Python-based benchmarking framework to evaluate cloud database performance using configurable datasets and benchmark workloads.

##  Project Overview

CognODB Cloud Benchmark is designed to measure database-related operations such as data loading, query execution, and performance metrics. The framework provides a structured way to run benchmark tests and generate execution reports.

##  Features

- Dataset loading and processing
- Configurable benchmark execution
- Performance measurement
- Query execution time tracking
- Automated result generation
- JSON-based benchmark reports
